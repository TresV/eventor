# Event Tickets User Guide

This guide is for site owners, content editors, event managers, and non-technical administrators. It explains how to use the plugin in plain language.

## What you can do with the plugin

- create and publish events
- display events with Elementor widgets and templates
- issue tickets and send attendee emails
- attach PDF and ICS delivery assets
- configure cancellation and event-day check-in
- assign a Staff role for operational users
