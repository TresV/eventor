# Create an Event

## Basic flow

1. Open `Event Tickets -> Events -> Add New`.
2. Enter the event title and description.
3. Set start and end date/time.
4. Add location details.
5. Configure attendance and ticketing rules.
6. Review status and visibility settings.
7. Publish the event.

## Before publishing

- confirm the event dates are correct
- confirm the location or virtual-access details are complete
- confirm ticketing mode and capacity match the real event
- test one ticket request
