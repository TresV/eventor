
# Първи стъпки

Използвайте този път, ако искате най-бързия маршрут от активация до работещ поток за събития и билети.

## Бърз маршрут

1. Активирайте Event Tickets for Elementor.
2. Активирайте Elementor.
3. Отворете `Event Tickets -> Get Started`.
4. Създайте стартовите страници.
5. Създайте първото събитие.
6. Настройте email и PDF.
7. Тествайте един пълен поток за билет преди да пуснете сайта.

## Препоръчителни стартови страници

- Events
- Get Ticket
- Ticket Actions
- Staff Check-in
