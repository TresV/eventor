
# Първи стъпки

Използвайте този път, ако искате най-бързия маршрут от активация до работещ поток за събития и билети.

## Бърз маршрут

1. Активирайте Event Tickets for Elementor.
2. Активирайте Elementor.
3. Активирайте WooCommerce само ако ще продавате платени билети.
4. Отворете `Event Tickets -> Get Started`.
5. Създайте стартовите страници.
6. Създайте първото събитие.
7. Настройте email и PDF.
8. Тествайте един пълен поток за билет преди да пуснете сайта.

## Препоръчителни стартови страници

- Events
- Get Ticket
- Ticket Actions
- Staff Check-in
