
# Създаване на събитие

## Основен поток

1. Отворете `Event Tickets -> Events -> Add New`.
2. Въведете име и описание на събитието.
3. Задайте начална и крайна дата/час.
4. Добавете данни за локацията.
5. Настройте attendance и ticketing правилата.
6. Прегледайте status и visibility настройките.
7. Публикувайте събитието.

## Преди публикуване

- потвърдете, че датите са правилни
- потвърдете, че локацията или virtual-access данните са пълни
- потвърдете, че ticketing mode-ът и капацитетът отговарят на реалното събитие
- тествайте една ticket заявка
