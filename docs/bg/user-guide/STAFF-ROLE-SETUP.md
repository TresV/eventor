
# Настройка на Staff ролята

Използвайте вградената Staff роля, когато искате оперативните хора в деня на събитието да работят с билети и check-in, без да им давате пълен администраторски достъп.

## Важна разлика

- администраторите и editor потребителите вече имат пълен достъп до административната част на Event Tickets
- използвайте Staff ролята само за оперативни потребители, които не трябва да получават пълното работно пространство на плъгина

## Стъпки за настройка

1. Отворете `Event Tickets -> Staff`.
2. В `Staff Access` изберете кои capability групи да получава Staff ролята.
3. Задайте Staff check-in page URL, ако реалната ви страница не е на default starter path.
4. Запазете правилата за достъп.
5. В `Staff Users` назначете съществуващи WordPress потребители към Staff ролята.
6. Влезте с тестов Staff акаунт и потвърдете:
   - `Event Tickets` отваря Tickets list
   - `Visit Site` отваря правилната check-in страница
   - потребителят може да прави само това, което сте планирали

## Практическа препоръка

Започнете само с capability групата за Event Tickets и добавяйте допълнителни WordPress права само ако имате реална оперативна причина.
