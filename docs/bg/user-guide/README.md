
# Ръководство на потребителя за Event Tickets

Това ръководство е за собственици на сайтове, редактори на съдържание, event мениджъри и нетехнически администратори. То обяснява как се използва плъгинът на разбираем език.

## Какво можете да правите с плъгина

- да създавате и публикувате събития
- да показвате събитията с Elementor widgets и templates
- да издавате билети и да изпращате attendee имейли
- да прикачвате PDF и ICS файлове
- да настройвате cancellation и check-in в деня на събитието
- да назначавате Staff роля за оперативни потребители
