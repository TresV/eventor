
# Преглед на настройките

## Основни settings области

- Email
- Event Settings
- Elementor
- PDF
- Payments

## Важна текуща бележка

Staff достъпът вече не се редактира от Settings. Управлява се от `Event Tickets -> Staff`.

Администраторите и editor потребителите имат пълен достъп до Event Tickets settings и административните екрани на плъгина.
