
# Обяснение на event полетата

## Основни секции

- Basics: заглавие, съдържание, основно изображение, taxonomy summary
- Schedule: начало, край и допълнителни timeslot-и
- Location: адрес, map URL, координати, държава, град
- Attendance and Ticketing: капацитет, лимити по имейл, ticketing mode
- Delivery: virtual или hybrid access детайли
- Status and Visibility: cancelled, postponed, badges
- Ticket Output: PDF preset и шаблон за ticket code

## Практическо правило

Ако дадено поле влияе на това какво вижда или получава посетителят, тествайте го с пробен билет след save.
