
# Модул: Администрация, настройки и операции

## Цел

Документира admin UI-то, schema-та на настройките, експортите, инструментите и оперативните потоци.

## Основни admin екрани

- Dashboard
- Get Started
- Events
- Tickets
- Staff
- Settings
- Tools
- Documentation
- User Guide

## Модел на достъп

- администраторите и editor потребителите вече споделят пълен достъп до административните екрани на Event Tickets
- това е достъп само в рамките на плъгина, а не пълен site-wide администраторски достъп
- ролята Staff остава отделна оперативна роля за check-in и работа с билети

## Настройки

- Email
- event status badges
- Elementor
- PDF
- Payments

Staff access вече се управлява от отделния Staff екран, а не от Settings табовете.

## Оперативни функции

- ticket list и ръчни редакции
- CSV експорти
- repair инструменти
- user-guide и technical-documentation работни пространства
