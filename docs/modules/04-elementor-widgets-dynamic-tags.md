# Module: Elementor Widgets and Dynamic Tags

## Purpose

Describes the Elementor integration layer used to render events, accept ticket requests, and expose event data inside templates.

## Current scope

- Events Browser
- Ticket Box
- Ticket view / resend / cancel / PDF widgets
- Check-in widget
- event dynamic tags, including Event Status

## Current implementation notes

- Event Status now uses the shared status resolver
- dynamic-tag output can be filtered by selected statuses
- status badges and labels stay aligned with the shared event status system

# Модул: Elementor widgets и dynamic tags

## Цел

Описва Elementor integration слоя, който рендерира събития, приема заявки за билети и излага event data в templates.

## Текущ обхват

- Events Browser
- Ticket Box
- widgets за ticket view / resend / cancel / PDF
- Check-in widget
- event dynamic tags, включително Event Status

## Текущи бележки

- Event Status вече използва споделения status resolver
- изходът на dynamic tag-а може да се филтрира по избрани статуси
- status badges и labels остават синхронизирани със споделената event status система
