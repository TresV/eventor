# Module: Admin, Settings, and Operations

## Purpose

Documents the admin-side UI, settings schema, exports, tools, and operational workflows.

## Main admin screens

- Dashboard
- Get Started
- Events
- Tickets
- Staff
- Settings
- Tools
- Documentation
- User Guide

## Access model

- administrators and editors now share full access to the Event Tickets plugin admin screens
- this is plugin-scoped access, not full site administration
- the Staff role remains a separate operational role for check-in and ticket work

## Settings areas

- Email
- Event status badges
- Elementor
- PDF
- Payments

Staff access is now managed from the dedicated Staff screen rather than the Settings tabs.

## Operational functions

- ticket list and manual edits
- CSV exports
- repair tools
- user-guide and technical-documentation workspaces
