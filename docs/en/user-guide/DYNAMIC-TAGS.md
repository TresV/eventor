# Dynamic Tags

Use dynamic tags inside Elementor templates when the same layout should adapt automatically to the current event.

## Important current note

The Event Status dynamic tag can now be limited to selected statuses, for example only `Cancelled` and `Over`.

## Display Conditions

If Elementor Pro is active, Event templates can use post-style display conditions under `Singular > Event`, including `Events`, `In Category`, `In Child Categories`, `In Tag`, and `Events by author`.
