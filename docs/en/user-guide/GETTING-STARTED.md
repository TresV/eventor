# Getting Started

Use this path if you want the fastest route from activation to a working event and ticket flow.

## Quick path

1. Activate Event Tickets for Elementor.
2. Activate Elementor.
3. Open `Event Tickets -> Get Started`.
4. Create the starter pages.
5. Create your first event.
6. Configure email and PDF settings.
7. Test one full ticket flow before going live.
