# Getting Started

Use this path if you want the fastest route from activation to a working event and ticket flow.

## Quick path

1. Activate Event Tickets for Elementor.
2. Activate Elementor.
3. Activate WooCommerce only if you will sell paid tickets.
4. Open `Event Tickets -> Get Started`.
5. Create the starter pages.
6. Create your first event.
7. Configure email and PDF settings.
8. Test one full ticket flow before going live.
