# Event Fields Explained

## Main sections

- Basics: title, content, featured image, taxonomy summary
- Schedule: start, end, and optional timeslots
- Location: address, map URL, coordinates, country, city
- Attendance and Ticketing: capacity, per-email limits, ticketing mode
- Delivery: virtual or hybrid access details
- Status and Visibility: cancelled, postponed, badges
- Ticket Output: PDF preset and ticket code pattern

## Practical rule

If a field affects what the attendee sees or receives, test it with a sample ticket after saving.
